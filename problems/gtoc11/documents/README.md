# Documentary sources

The final problem statement is dated **16 October 2021** and is published by
the organizers via the [ESA GTOC portal](https://sophia.estec.esa.int/gtoc_portal/wp-content/uploads/2021/12/gtoc11_problem_stmt.pdf).
It specifies **alpha=6e-9 s^-1**. The benchmark's `../statement.md` and
`../submission-format.md` provide the mathematical reference and serialization
instructions used with the supplied official checker.

On 3 November 2026 the original GTOC11 site timed out and direct retrieval from
the ESA portal returned certificate errors / HTTP 503. The final statement's
indexed text and the organizers' published problem/results paper were used to
confirm the corrected coefficient, constants, constraints and submission format.
No unavailable PDF is represented as a downloaded original.

An unchanged PDF from a participant repository, dated **10 October 2021**, was
also recovered and inspected. It contains the superseded alpha=1e-9 and is
therefore retained only among host-side source references, outside agent inputs.
The benchmark does not silently modify that historical PDF or present it as
the final rules. The original Linux executable and full asteroid catalogue
were supplied directly and do not depend on the availability of either site.
